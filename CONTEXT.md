# Bash Workbench Context

Bash Workbench supports software development in a Bash.tv space. This context separates the development tool from the software that the user wants to build.

## Language

**Bash Workbench**:
A background development tool that lets people and agents view and control work in a Bash.tv space.
_Avoid_: App, user app, deliverable

**User project**:
The separate application or repository that the user asks the Bash.tv agent to build.
_Avoid_: Workbench, Workbench project

**Registered project**:
A user project that is visible and controllable in Bash Workbench.
_Avoid_: Configured folder, mounted project
